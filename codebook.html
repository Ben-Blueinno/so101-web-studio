SO-101 Python Codebook

Edit a route in Web Studio and select Preview in 3D. The examples use the standard SO-101 LeRobot API.

Move one joint and return

def route(robot):
    start = robot.get_observation()
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + 8})
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

get_observation() reads calibrated joint positions. send_action() takes a joint key and a target position. Each body joint target uses the corresponding starting position plus or minus a degree offset.

Body joint keys are shoulder_pan.pos, shoulder_lift.pos, elbow_flex.pos, wrist_flex.pos, and wrist_roll.pos.

Use the gripper

def route(robot):
    start = robot.get_observation()
    robot.send_action({"gripper.pos": 45})
    robot.send_action({"gripper.pos": 33})

The gripper target is an absolute percentage of its calibrated travel. The Studio preview supports one joint per action.

Reuse a number and repeat moves

def route(robot):
    start = robot.get_observation()
    turn = 6
    for attempt in range(2):
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + (turn + attempt * 2)})
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

Keep the offset in a variable or put parentheses around a calculation, as in start["shoulder_pan.pos"] + (turn + attempt * 2). The editor supports numeric variables, arithmetic, and bounded loops. Routes can contain up to 32 moves. Errors show the line to check.

Export to your project

Open Export to a LeRobot project and generate the function. The downloaded module uses your connected, calibrated SO101Follower with use_degrees=True and reads position feedback while moving.

from my_route_lerobot import run_route

run_route(robot)
