SO-101 Python Codebook

A route is a set of moves the arm follows in order. Try each example in the Web Studio Python editor and choose Preview in 3D.

Find the six motors

A motor turns one joint. Pick a motor below to highlight it in gold, then drag the model to see it from another angle.

MotorPython keyWhat moves
shoulder_pan.posTurns the base left or right.
shoulder_lift.posRaises or lowers the upper arm.
elbow_flex.posBends or straightens the elbow.
wrist_flex.posTilts the gripper up or down.
wrist_roll.posTwists the gripper like a doorknob.
gripper.posOpens or closes the jaws.

1. Give a motor a target angle

def route(robot):
    robot.send_action({"wrist_roll.pos": -5})
    robot.send_action({"wrist_roll.pos": 0})
  1. def route(robot): names the function. Indent its instructions by four spaces.
  2. robot.send_action(...) gives one motor a target. The quoted key picks the motor and the number sets the angle in degrees.
  3. The wrist goes to −5° first and then 0°. Change −5 to −10 and preview again to see the difference.

The simulator uses default SO-101 limits. When the arm is connected by USB, Studio checks its calibrated limits.

2. Move a few degrees from where you start

def route(robot):
    start = robot.get_observation()
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + 8})
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

get_observation() reads all six starting positions. start["shoulder_pan.pos"] picks the base angle from those readings. If it starts at 10°, adding 8 sends it to 18°. The last line sends it back to 10°. You can skip the observation line when all targets are fixed numbers.

3. Open and close the gripper

def route(robot):
    robot.send_action({"gripper.pos": 45})
    robot.send_action({"gripper.pos": 33})

The gripper uses a percentage of its travel, from 0 to 100. Use one send_action() line for each motor you want to move.

4. Repeat a move with a loop

def route(robot):
    start = robot.get_observation()
    turn = 6
    for attempt in range(2):
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + (turn + attempt * 2)})
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

range(2) repeats the indented lines twice. Python starts counting at 0, so the first turn adds 6° and the second adds 8°. Change turn to 3 and predict both turns before previewing. Keep each route to 32 moves or fewer.

Export to your project

Open Export to a LeRobot project and generate the function. The downloaded module uses your connected, calibrated SO101Follower with use_degrees=True and reads position feedback while moving.

from my_route_lerobot import run_route

run_route(robot)

In Web Studio, select Start here for connection and calibration instructions. After previewing, choose Prepare deployment and review the full route with your teacher. Select Confirm and run route once to run the moves in order.
