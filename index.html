SO-101 Web Studio

Browser simulator

Your first SO-101 route

  1. USB connectionPick your controller and read all six joints.
  2. CalibrationCapture joint ranges or restore a saved file over USB.
  3. SimulationRun the starter in the simulator.
  4. DeploymentCheck the targets and watch the live readings.

  1. USB connection

    Use desktop Chrome or Edge on Mac or Windows. Secure the arm to the bench, connect its motor power and USB cable, and close any other app using its serial port. In USB connection, select the follower profile and choose Scan ports. Pick the controller in the browser’s port picker. If the arm is already calibrated, choose Connect by USB. For a new arm, open Calibration next.

    Choose Read current pose. Look for all six joint readings, then check that Simulation shows Live encoder pose. A calibrated arm can connect directly through the browser with its existing settings.

  2. Calibrate over USB

    For a new assembled arm, open Calibration and select Calibrate new. If the chooser appears, select the SO-101 adapter. Support the arm when torque releases. Put the joints near the middle of their travel and select Capture midpoint. Gently move each joint through its range by hand, skipping wrist roll, then choose Save range.

    To restore a calibration for the same arm, open Settings and choose Import JSON, Save calibration, Use for profile, and Save profile. Select that follower in USB connection, then open Calibration and choose Restore saved calibration. Once Studio verifies the settings, return to USB connection and choose Connect by USB.

  3. Simulation

    Open Simulation and choose Preview in 3D. The starter turns wrist roll to −5° and then to 0°. Change an angle and preview again. The simulator uses default joint limits when no arm is connected.

    def route(robot):
    robot.send_action({
        "wrist_roll.pos": -15,
        "gripper.pos": 55,
    })

    Put both targets in the same call to move the wrist and gripper together.

  4. Deployment

    Read the current pose before planning the first move. For a small test, set a wrist roll target a few degrees from its measured angle and within its calibrated limits. Run Preview in 3D in Simulation. Then open Deployment and choose Prepare deployment.

    For moves with more than one joint, use Connect by USB after calibration.

    Review every joint and target in the list. Check the entire path with your teacher, keep hands clear, and choose Confirm and run route once. The moves run in order and the 3D view follows the encoder readings. Use Stop route if the arm moves unexpectedly.

If the controller does not appear in the port picker, check that the USB cable carries data and that no other app has the port open. If the controller appears but Studio cannot read the joints, check the motor power and the cable to the first servo.
