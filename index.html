1. Give a motor a target angle

def route(robot):
    robot.send_action({"A.wrist_roll.pos": -5})
    robot.send_action({"A.wrist_roll.pos": 0})
  1. def route(robot): names the function. Indent its instructions by four spaces.
  2. robot.send_action(...) gives one motor a target. The quoted key picks the motor and the number sets the angle in degrees.
  3. The wrist goes to −5° first and then 0°. Change −5 to −10 and preview again to see the difference.

2. Move a few degrees from where you start

def route(robot):
    start = robot.get_observation()
    robot.send_action({"A.shoulder_pan.pos": start["A.shoulder_pan.pos"] + 8})
    robot.send_action({"A.shoulder_pan.pos": start["A.shoulder_pan.pos"]})

get_observation() records the route’s starting positions. start["shoulder_pan.pos"] picks the base angle from those readings. If it starts at 10°, adding 8 sends it to 18°. The last line sends it back to 10°. You can skip the observation line when all targets are fixed numbers. Every key still starts with A. or B.

3. Open and close the gripper

def route(robot):
    robot.send_action({"A.gripper.pos": 45})
    robot.send_action({"A.gripper.pos": 33})

The gripper uses a percentage of its travel, from 0 to 100.

4. Move two joints together

def route(robot):
    wrist_angle: float = -5.0
    robot.send_action({
        "A.wrist_roll.pos": wrist_angle,
        "A.gripper.pos": 45,
    })
    robot.send_action({"A.wrist_roll.pos": 0, "A.gripper.pos": 33})

Targets inside the same send_action() move together. Studio waits for both targets before starting the next call. The optional : float type hint tells readers that the variable can contain a decimal. Use : int for a whole number. Type robot. or start typing a quoted joint key for suggestions.

Try grouped moves in the 3D preview first. For a physical run, connect a calibrated arm by USB and check the path of all moving joints together before confirming.

Move both arms and return to rest

def route(robot):
    start = robot.get_observation()
    robot.send_action({
        "A.wrist_roll.pos": start["A.wrist_roll.pos"] - 5,
        "B.wrist_roll.pos": start["B.wrist_roll.pos"] + 5,
    })
    robot.send_action({
        "A.wrist_roll.pos": start["A.wrist_roll.pos"],
        "B.wrist_roll.pos": start["B.wrist_roll.pos"],
    })
  1. A is the robot’s right arm. B is its left arm. Both face forward in the shared preview.
  2. start records the starting positions. Each wrist’s starting angle is its rest target for this exercise.
  3. The first call moves A’s wrist −5° and B’s wrist +5° together. The second call returns both to their recorded angles.
  4. Preview first. Watch both wrist motors highlight during each step, then clear when the route ends.

For a physical run, connect both arms and read each current pose before previewing. To start from saved rest, open Pose and rest in each arm’s actions menu and use Return to rest first.

5. Repeat a move with a loop

def route(robot):
    start = robot.get_observation()
    turn = 6
    for attempt in range(2):
        robot.send_action({"A.shoulder_pan.pos": start["A.shoulder_pan.pos"] + (turn + attempt * 2)})
        robot.send_action({"A.shoulder_pan.pos": start["A.shoulder_pan.pos"]})

range(2) repeats the indented lines twice. Python starts counting at 0, so the first turn adds 6° and the second adds 8°. Change turn to 3 and predict both turns before previewing. Keep each route to 32 moves or fewer.

Export to your project

Open Files and choose Generate LeRobot function. The downloaded module uses your connected, calibrated SO101Follower with use_degrees=True and reads position feedback while moving.

from my_route_lerobot import run_route

Save and export

Name the program and select the save icon to keep it in this browser. In Files, choose Download Python source to keep the full A/B route.

Generate LeRobot function supports one named arm per export. Download Python source to keep a complete two-arm route.

In Web Studio, select Start here for connection and calibration instructions. After previewing, choose Prepare deployment and review the full route with your teacher. Select Confirm and run route once to run the moves in order.

    From SO-101 to XLeRobot

    1. Available now

      Write a Python route, preview it in 3D, then replay it over USB on one SO-101.

    2. Classroom hardware now

      Calibrate each arm, then connect both and program a route for one or both followers. No cameras needed.

    3. Use basic computer vision to find an object. Let each arm move to its own target.

    4. Locate objects in 3D and coordinate the arms for tasks such as holding with one arm and picking with the other.

    5. Mount both arms on the base. Practise driving, turning, and stopping with the arms parked.

    6. Use the depth camera to see obstacles and navigate to a target.

    7. Drive to an object, stop and line up, then use the arms to pick it up.

    8. Move control from the laptop to a Raspberry Pi or similar onboard computer. Run navigation, vision, and arm control together.

    About Web Studio

    Students learn to program a robot arm in Python, test routes on a 3D SO-101, and run reviewed routes on a real follower over USB.

    Simulation
    Runs in the browser. No arm required.
    USB control
    Use desktop Chrome or Edge on Mac or Windows. Connect one or two calibrated followers using separate USB adapters.
    LeRobot projects
    Export a Python function for a connected SO101Follower.
