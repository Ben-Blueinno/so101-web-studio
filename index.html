1. Give a motor a target angle

def route(robot):
    robot.send_action({"wrist_roll.pos": -5})
    robot.send_action({"wrist_roll.pos": 0})
  1. def route(robot): names the function. Indent its instructions by four spaces.
  2. robot.send_action(...) gives one motor a target. The quoted key picks the motor and the number sets the angle in degrees.
  3. The wrist goes to −5° first and then 0°. Change −5 to −10 and preview again to see the difference.

2. Move a few degrees from where you start

def route(robot):
    start = robot.get_observation()
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + 8})
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

get_observation() reads all six starting positions. start["shoulder_pan.pos"] picks the base angle from those readings. If it starts at 10°, adding 8 sends it to 18°. The last line sends it back to 10°. You can skip the observation line when all targets are fixed numbers.

3. Open and close the gripper

def route(robot):
    robot.send_action({"gripper.pos": 45})
    robot.send_action({"gripper.pos": 33})

The gripper uses a percentage of its travel, from 0 to 100.

4. Move two joints together

def route(robot):
    wrist_angle: float = -5.0
    robot.send_action({
        "wrist_roll.pos": wrist_angle,
        "gripper.pos": 45,
    })
    robot.send_action({"wrist_roll.pos": 0, "gripper.pos": 33})

Targets inside the same send_action() move together. Studio waits for both targets before starting the next call. The optional : float type hint tells readers that the variable can contain a decimal. Use : int for a whole number. Type robot. or start typing a quoted joint key for suggestions.

Try grouped moves in the 3D preview first. For a physical run, connect a calibrated arm by USB and check the path of all moving joints together before confirming.

5. Repeat a move with a loop

def route(robot):
    start = robot.get_observation()
    turn = 6
    for attempt in range(2):
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + (turn + attempt * 2)})
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

range(2) repeats the indented lines twice. Python starts counting at 0, so the first turn adds 6° and the second adds 8°. Change turn to 3 and predict both turns before previewing. Keep each route to 32 moves or fewer.

    About Web Studio
    
  
    Built for Grade 10 robotics. Students write Python, test routes on a 3D SO-101, and run reviewed routes on a real follower over USB.
    
  
    
    
    Simulation
    Runs in the browser. No arm required.
    
    
    USB control
    Use desktop Chrome or Edge on Mac or Windows. Studio connects to one calibrated follower at a time.
    
    
    LeRobot projects
    Export a Python function for a connected SO101Follower.
