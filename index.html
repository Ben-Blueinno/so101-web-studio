Your first SO-101 route

  1. Preview in 3DRun the starter in the simulator.
  2. Connect by USBPick your controller and read all six joints.
  3. Calibrate if neededPair the bridge for a new or saved calibration.
  4. Review and runCheck the targets and watch the live readings.

  1. Try the simulator

    Open Python & 3D and choose Preview in 3D. The starter turns wrist roll to −5° and then to 0°. Change an angle and preview again. The simulator uses default joint limits when no arm is connected.

    def route(robot):
    robot.send_action({
        "wrist_roll.pos": -15,
        "gripper.pos": 55,
    })

    Put both targets in the same call to move the wrist and gripper together.

  2. Connect an already calibrated arm

    Use desktop Chrome or Edge on Mac or Windows. Secure the arm to the bench, connect its motor power and USB cable, and close any other app using its serial port. In Arm setup, select the follower profile for that arm, then choose Connect by USB and select the controller in the browser’s port picker.

    Choose Read current pose. Look for all six joint readings, then check that Python & 3D shows Live encoder pose. A calibrated arm can connect directly through the browser with its existing settings.

  3. Set up calibration if the arm needs it

    With your teacher, download and unzip the Studio bridge. Follow START HERE.txt to set up Python and LeRobot and launch the Mac or Windows bridge. Leave its terminal open. In Arm setup, expand Use the local bridge, paste the pairing code, and choose Connect bridge. Allow local access if prompted.

    In Settings, choose the follower profile, select the arm’s serial port and Save profile. On Windows the port usually starts with COM. On Mac it usually starts with /dev/cu.usb.

    • Restore a calibration for this same arm. In Settings, choose Import JSON, Save calibration, Use for profile, then Save profile. In Arm setup, select the same follower and choose Apply saved calibration. Support the arm before confirming because this releases torque.
    • Calibrate a new arm. Select the follower in Arm setup and choose Calibrate new. Support the arm when torque releases. Follow the prompts to place the joints near the middle of their travel and select Capture midpoint. Gently move each joint through its usable travel, skipping wrist roll as instructed. Select Save range.

    Once calibration succeeds, close the bridge and reload Web Studio to use Connect by USB. If you initialized the arm through the bridge, support it and choose Disconnect arm before closing the bridge.

  4. Preview and deploy your route

    Read the current pose before planning the first move. For a small test, set a wrist roll target a few degrees from its measured angle and within its calibrated limits. In Python & 3D, run Preview in 3D, then choose Prepare deployment.

    For moves with more than one joint, use Connect by USB after calibration.

    Review every joint and target in the list. Check the entire path with your teacher, keep hands clear, and choose Confirm and run route once. The moves run in order and the 3D view follows the encoder readings. Use Stop route if the arm moves unexpectedly.

If the controller does not appear in the port picker, check that the USB cable carries data and that no other app has the port open. If the controller appears but Studio cannot read the joints, check the motor power and the cable to the first servo.
