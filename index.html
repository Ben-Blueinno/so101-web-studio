Browser simulator

Write your first arm route

Use Python to move the 3D arm. When your route looks right, try it on your SO-101 with your teacher.

You can start coding without an arm.

  1. USB connection

    Secure the arm to the bench. Plug in motor power and USB. Open Studio in desktop Chrome or Edge on Mac or Windows.

    In USB connection, select your follower, click Scan ports, and pick the SO-101 adapter. If the arm is already calibrated, click Connect by USB, then Read current pose. Check for six readings. For a new arm, go to Calibration first.

  2. Calibration

    For a new arm, select Calibrate new. Support the arm as torque releases. Place the joints near the middle of their travel and choose Capture midpoint. Gently move each joint through its range by hand, skipping wrist roll. Choose Save range.

    Restore a file for this arm

    In Settings, click Import JSON, Save calibration, Use for profile, then Save profile. Use only a file saved for this same arm. Select the follower in USB connection, then choose Restore saved calibration in Calibration. After Studio verifies the settings, return to USB connection and click Connect by USB.

  3. Simulation

    Click Preview in 3D. The starter turns the wrist to −5°, then back to 0°. Change −5 to −10 and preview again. Find the range and Python key for each motor with the Codebook switch above the 3D preview.

  4. Deployment

    Start with the current pose. For your first move, pick a wrist roll target a few degrees away and within the arm’s calibrated range. Preview it, open Deployment, and choose Prepare deployment.

    Review every target and check the full path with your teacher. With hands clear, click Confirm and run route once. Watch the 3D view follow the arm’s readings. Click Stop route if the arm moves unexpectedly.

Move two joints together

Put both targets in one call. Play the example and watch the wrist and gripper.

def route(robot):
    robot.send_action({
        "wrist_roll.pos": -15,
        "gripper.pos": 55,
    })

Can’t find the adapter or read the joints?

Try a USB data cable and close other apps that may be using the port. If the adapter shows up but the joints don’t, check the arm’s motor power and the cable to the first servo.

1. Give a motor a target angle

def route(robot):
    robot.send_action({"wrist_roll.pos": -5})
    robot.send_action({"wrist_roll.pos": 0})
  1. def route(robot): names the function. Indent its instructions by four spaces.
  2. robot.send_action(...) gives one motor a target. The quoted key picks the motor and the number sets the angle in degrees.
  3. The wrist goes to −5° first and then 0°. Change −5 to −10 and preview again to see the difference.

2. Move a few degrees from where you start

def route(robot):
    start = robot.get_observation()
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + 8})
    robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

get_observation() reads all six starting positions. start["shoulder_pan.pos"] picks the base angle from those readings. If it starts at 10°, adding 8 sends it to 18°. The last line sends it back to 10°. You can skip the observation line when all targets are fixed numbers.

3. Open and close the gripper

def route(robot):
    robot.send_action({"gripper.pos": 45})
    robot.send_action({"gripper.pos": 33})

The gripper uses a percentage of its travel, from 0 to 100.

4. Move two joints together

def route(robot):
    wrist_angle: float = -5.0
    robot.send_action({
        "wrist_roll.pos": wrist_angle,
        "gripper.pos": 45,
    })
    robot.send_action({"wrist_roll.pos": 0, "gripper.pos": 33})

Targets inside the same send_action() move together. Studio waits for both targets before starting the next call. The optional : float type hint tells readers that the variable can contain a decimal. Use : int for a whole number. Type robot. or start typing a quoted joint key for suggestions.

Try grouped moves in the 3D preview first. For a physical run, connect a calibrated arm by USB and check the path of all moving joints together before confirming.

5. Repeat a move with a loop

def route(robot):
    start = robot.get_observation()
    turn = 6
    for attempt in range(2):
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"] + (turn + attempt * 2)})
        robot.send_action({"shoulder_pan.pos": start["shoulder_pan.pos"]})

range(2) repeats the indented lines twice. Python starts counting at 0, so the first turn adds 6° and the second adds 8°. Change turn to 3 and predict both turns before previewing. Keep each route to 32 moves or fewer.
